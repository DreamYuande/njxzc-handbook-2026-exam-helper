# 南京晓庄学院2026年学生手册正式考试助手

用于 [南京晓庄学院2026年学生手册正式考试](https://ks.wjx.com/vm/YDD4gnE.aspx) 的 JavaScript 用户脚本，当前版本 **1.0.0**，使用 MIT License。

**第一次使用请先看 [从零安装教程](安装教程.md)**：包含 Chrome / Edge 安装 Tampermonkey、开启“允许用户脚本”及“开发者模式”、设置网站访问权限、安装脚本和故障排查。

## 安装入口

- [点击安装正式版脚本](https://raw.githubusercontent.com/DreamYuande/njxzc-handbook-2026-exam-helper/main/南京晓庄2026学生手册正式考试助手.user.js)
- [从零安装教程（含运行权限设置）](安装教程.md)
- [功能、使用说明与验证范围](正式考试助手_使用说明.md)
- [打开对应正式考试页面](https://ks.wjx.com/vm/YDD4gnE.aspx)

如果安装链接只显示代码或下载文件，按教程中的“手动粘贴安装”操作。安装成功后，Tampermonkey 管理面板中应出现“南京晓庄2026学生手册正式考试助手”且保持启用。

## 功能

- 在本机保存姓名、学院、学号，保存后刷新，先填写基本信息，再按参考题库作答。
- 按题干、题型及完整选项文本匹配，支持选项顺序变化，不依赖页面题号和内部 topic 编号。
- 未匹配、答案待确认或选项不一致时默认跳过；可选“单选随机 / 多选全选”兜底，浮窗列出待确认及异常。
- 支持暂停、继续、重填、拖动与折叠；浮窗支持较小屏幕下展开设置与滚动。
- 只匹配指定正式考试链接，并在运行时再次核对地址。
- 不自动翻页、提交或处理验证码。检查后需自行提交。

## 开始使用

1. 按 [安装教程](安装教程.md) 完成油猴、运行权限和正式版脚本安装。
2. 打开 [正式考试](https://ks.wjx.com/vm/YDD4gnE.aspx)，在右下角“基本信息设置”中填写姓名、学院、学号。
3. 点击“保存信息”，然后刷新页面。
4. 检查填写结果与“待确认及异常”，手动处理需要确认的题目，最后自行提交。

新版 Chrome 的“允许用户脚本”在 **扩展管理 → Tampermonkey → 详情** 中；Chrome 138 之前的版本使用扩展管理页的“开发者模式”。Edge 按教程检查当前版本提供的开关。不要把按 F12 打开的开发者工具当作这些开关。详见 [Chrome 官方说明](https://developer.chrome.com/docs/extensions/reference/api/userScripts) 与 [Tampermonkey 官方说明](https://www.tampermonkey.net/faq.php?q=Q209)。

## 数据、题库及验证

脚本没有额外的网络请求或数据上传逻辑。姓名、学院、学号保存在 `ks.wjx.com` 的 localStorage，键为 `njxzc.handbook.profile.v1`；与旧模拟版共用。已保存完整信息的用户，首次打开正式版页面就可能自动读取并填写。正式版兜底设置单独保存。

参考题库保留旧模拟版 1.2.2 的 325 条记录，包括已更正的四道题；316 条带参考答案，9 条待确认。题库命中与随机／全选均不能视为官方答案确认。本次未重新审定整套题库。

已完成语法检查、948 个带答案记录的选项排列映射用例和 27 个待确认记录跳过用例；本次正式页面副本的 35 道题均能匹配到带参考答案的记录。页面控件副本上的填写、暂停、重填及手机尺寸浮窗检查通过，**尚未在真实考试页安装运行或提交验证**。完整边界见 [使用说明](正式考试助手_使用说明.md)。

本地语法检查：

```sh
node --check "南京晓庄2026学生手册正式考试助手.user.js"
```
