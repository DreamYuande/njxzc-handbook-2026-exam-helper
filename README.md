# 南京晓庄学院2026年学生手册正式考试助手

用于南京晓庄学院2026年学生手册正式考试（`YDD4gnE` 页面）的 JavaScript 用户脚本，当前版本 **1.4.1**，使用 MIT License。浮窗标题下方也会显示脚本版本号。

## 已用过油猴：一键安装

如果你已经在**当前浏览器**用 Tampermonkey 正常运行过其他脚本，可以直接安装本脚本，无需重新安装油猴扩展。

1. **[点击一键安装正式版脚本](https://raw.githubusercontent.com/DreamYuande/njxzc-handbook-2026-exam-helper/main/南京晓庄2026学生手册正式考试助手.user.js)** → 在油猴弹出的确认页点击“安装”；已有本脚本时按提示更新。
2. 安装后，[打开正式考试页面](https://ks.wjx.com/vm/YDD4gnE.aspx)；如果页面原本已打开，按 `F5` 刷新。
3. 在助手顶部选择模式，填写姓名、学院、8位数字学号。标准模式点“保存并填写”，不刷新、手动提交；竞速模式点“保存并竞速”，刷新后从页面加载开始计时，并行填写，到设定秒数检查并提交（最低2秒）。左侧“临时保存信息”只保存草稿。

“一键安装”链接会打开油猴的安装确认页，仍需你点击确认。若出现新增权限提示，核对脚本名称为“南京晓庄2026学生手册正式考试助手”，题库连接目标为 `gh-proxy.com` 后确认。

只显示代码、只下载了文件或刷新后没有浮窗时，按 [安装教程](安装教程.md) 第 4.2 节手动安装，或第 7 节排查权限。标准模式确认填写结果后自行提交；竞速模式可在倒计时结束前点击“取消自动提交”。

## 没有用过油猴：从零安装

**完整顺序：安装油猴扩展 → 开启运行权限 → 安装正式版脚本。**

1. **安装油猴并开启权限：** 按 [从零安装教程](安装教程.md) 的第 1—3 节，完成 Tampermonkey 安装、“允许用户脚本”或对应版本的“开发者模式”设置，以及考试站点访问权限。
2. **安装正式版脚本：** 完成上一步后，[打开正式版脚本安装页](https://raw.githubusercontent.com/DreamYuande/njxzc-handbook-2026-exam-helper/main/南京晓庄2026学生手册正式考试助手.user.js)，核对名称为“南京晓庄2026学生手册正式考试助手”，再点击油猴页面中的“安装”。这个链接用于安装脚本，不会进入考试。
3. **确认安装完成：** 在 Tampermonkey“管理面板”中找到上述正式版脚本，并确认它已启用。只下载了文件、只安装了油猴或只安装了旧模拟版，都还没有完成正式版安装。

如果第 2 步只显示代码或下载文件，按 [安装教程](安装教程.md) 第 4.2 节“手动粘贴安装”完成安装。

## 已安装后使用：打开考试并填写

**确认正式版脚本已安装并启用后，再进行以下步骤。**

1. 在安装脚本的同一个浏览器中，[打开正式考试页面](https://ks.wjx.com/vm/YDD4gnE.aspx)。这个链接进入考试，不负责安装脚本。
2. 等待右下角出现助手浮窗，展开“基本信息设置”，填写姓名、学院、学号。
3. **标准模式（默认）：** 点击“保存并填写”，信息校验通过后直接填写当前页面，不刷新，最后自行检查并提交。
4. **竞速模式：** 切换顶部开关，设置“页面加载起计时（秒）”（不低于2的整数），点击“保存并竞速”。脚本保存信息并刷新，在不同题目之间并行填写；倒计时从刷新页开始加载计算，与填写并行，不等填完后重新计时；到时检查当前页面并点击一次提交按钮。可随时点“取消自动提交”，或切回标准模式。

姓名须填写、学院须在当前问卷中可用、学号须为8位数字；信息完整后可直接保存并开始，无需先临时保存。左侧“临时保存信息”仍可保存未填完整的草稿，不刷新、不开始。已存信息会自动读取，但普通打开或手动刷新不会自动开始，也不会自动提交。

竞速模式遇到无法处理的题目、未完成题或填写异常、可见验证码或页面错误时停止自动提交。修改模式、基本信息、提交秒数、兜底设置或检查题库更新也会取消自动提交，需要重新点击“保存并竞速”才会启用。只点击页面原生提交按钮一次，不绕过验证、不自动重试，不保证平台接受过快提交。

更多操作和验证范围见 [正式考试助手使用说明](正式考试助手_使用说明.md)。

## 更新题库（1.1.0 起）

安装时自带默认题库，首次运行与普通刷新不主动联网。助手浮窗会显示当前题库版本、题目数量和来源。

1. 旧版用户先按上方安装步骤更新到 **1.2.2** 并刷新考试页面；油猴如提示新增连接或存储权限，核对后确认。
2. 点击浮窗的 **“检查题库更新”**，脚本暂时停止填写，从本仓库的 [question-bank.json](question-bank.json) 检查新版题库，检查结束后恢复原来的填写状态。
3. 下载并校验通过后，新版题库保存在油猴的本地存储中，下次打开时继续使用；断网或更新失败时保留原有题库。
4. 检查成功后按钮灰显 20 秒，显示“当前已是最新(20)”并倒计时；下一行保留题库版本、题数和来源。未作答题可使用新题库，已完成题及手动调整保留。需要重新填写时，标准模式点击“保存并填写”；竞速模式点击“保存并竞速”，会重新启用自动提交。

**更新题库**只读取题目和参考答案；**更新脚本**才会获得新的按钮或程序功能。以后只有题库内容更正时，无需反复重装脚本。题库维护方法见 [题库更新说明](题库更新说明.md)。

## 功能

- 顶部滑动开关切换标准模式和竞速模式。标准模式保存后直接填写，不刷新、手动提交；竞速模式刷新后并行填写，自页面加载开始计时，达到设定秒数（最低2秒）后检查并点击一次提交，可取消。
- 支持临时保存不完整的信息草稿；打开或普通刷新页面不会直接开始。
- 按题干、题型及完整选项文本匹配，支持选项顺序变化，不依赖页面题号和内部 topic 编号。
- 标准模式默认跳过未匹配、待确认或选项不一致的题；竞速模式默认单选随机、多选全选。两种模式分别保存兜底选择，浮窗列出待确认及异常。
- 支持拖动与折叠；浮窗支持较小屏幕下展开设置与滚动，使用浅色细滚动条，版权页脚固定在底部。
- 自带默认题库，支持按钮从 GitHub 更新并保存；浮窗底部含版权信息和可点击的 GitHub 猫图标。
- 只匹配指定正式考试链接，并在运行时再次核对地址。
- 不自动翻页或处理验证码。标准模式手动提交；竞速模式仅在明确开始、全部填写和检查通过后尝试提交一次。

## 清除表单数据

“临时保存信息 / 保存并填写（或保存并竞速）”下方、版权行上方提供淡红底、红字的通栏“清除表单数据”按钮。确认后停止填写，尝试清除本脚本题库缓存、当前站点的本地信息、本标签页会话信息、可访问的 Cookie、离线缓存、数据库和离线服务，再刷新页面。网站数据由同站点页面共享，清理可能影响登录状态及未提交内容；与旧模拟版共用的基本信息也会删除。取消确认不会清理。

该按钮只能清理浏览器允许脚本访问的数据，不能等同于开发者工具的 Clear site data：HttpOnly Cookie、其他路径不可访问的 Cookie、其他站点或子域数据、浏览器网络缓存需在浏览器站点设置中清除。清理受权限、数据库占用或浏览器支持限制时，部分数据可能保留；仍会刷新页面，不再弹出或显示额外提示。刷新后网站可能重新生成必要数据。参见 [Cookie 访问限制](https://developer.mozilla.org/en-US/docs/Web/API/Document/cookie)及 [Clear-Site-Data 说明](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Clear-Site-Data)。

## 数据、题库及验证

只有点击“检查题库更新”时，脚本才会向固定的 `gh-proxy.com` 题库地址发起 GET 请求，不在请求中携带姓名、学号或作答内容，也不发送 Cookie。姓名、学院、学号保存在 `ks.wjx.com` 的 localStorage，键为 `njxzc.handbook.profile.v1`；与旧模拟版共用。已保存完整信息的用户，打开正式版页面会读取已保存信息，仍需点击当前模式的保存并开始按钮。正式版兜底设置单独保存，下载题库保存在油猴存储中。

题库为参考答案。当前题库版本、题目数量和来源以助手浮窗显示为准。页面抽题序号和选项顺序会变化，匹配使用题干和选项文本。题库命中与随机／全选均不能视为整套答案已得到官方确认。

已完成语法、题库乱序匹配及模式配置检查。**电脑版既有填写功能已在真实考试页面验证通过；v1.4.1 已通过本地浏览器副本的模式切换、并行填写、从页面加载起计时及取消条件检查；未进行真实考试自动提交测试。** 详细验证情况见 [使用说明](正式考试助手_使用说明.md)。

本地语法检查：

```sh
node --check "南京晓庄2026学生手册正式考试助手.user.js"
node --test tests/*.test.cjs
```

题库更新、缓存、格式校验、缺题拒绝、保存失败保留原题库、请求超时与错误响应测试通过；临时保存、填写流程、更新按钮倒计时及缓存重新加载已在本地页面副本中验证。双模式和竞速自动提交的验证范围为本地浏览器副本，未进行真实考试提交测试。
